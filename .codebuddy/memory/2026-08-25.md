## Git 环境备注
- 本机 Windows git 无全局 user.name/email，提交需用临时身份覆盖：`git -c user.name=... -c user.email=... commit`（不修改任何 config 文件，符合"禁止更新 git config"规则）。
- Shell 为 PowerShell Core，`cd /d` 无效，应使用 `Set-Location` / `cd "绝对路径"`。
- 仓库远端实际为 `schalkiii/workbuddy-auto-signin`（非 README 里的 88lin fork）。
